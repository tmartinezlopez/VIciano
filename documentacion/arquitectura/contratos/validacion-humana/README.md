# Validación humana

El brief establece el flujo general: la IA propone contenidos/learning targets, nivel de apoyo y evidencias en las capas longitudinal y transversal; el profesor confirma o corrige; la información validada se consolida con trazabilidad en la capa relacional. Con Luis, Nacho y profesores se concretarán el formato de checklist, sus campos y estados, y cómo registrar decisiones, correcciones, evidencias y fecha.
